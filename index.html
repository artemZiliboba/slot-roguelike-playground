Как начисляются очки

Считаются только горизонтальные ряды. Два одинаковых символа в одном ряду дают сумму их стоимости. Три одинаковых дают сумму ×2. ★ Wild заменяет недостающий символ, но сам стоит 0.

🍒 🍒 🍋5 + 5 = +10
🍒 🍒 🍒(5 + 5 + 5) ×2 = +30
🍒 ★ 🍒(5 + 0 + 5) ×2 = +20
🍋 🍋 🍋(8 + 8 + 8) ×2 = +48
🔔 🔔 🍒12 + 12 = +24
🍒 🍋 🔔нет пары = +0

Modifiers могут изменить эту математику. Их эффект всегда указан справа в Current Build.

Current Build

Символы, которые могут выпасть. ×N — число копий; больше копий повышает шанс выпадения.

Modifiers

Постоянно меняют scoring или поведение машины.

Developer Controls

Только для тестирования. Эти кнопки не означают «выдать символ в следующий Spin» — они меняют сам билд.

Add Symbol to Pool

Каждое нажатие добавляет 1 копию символа в пул. Чем больше копий, тем выше шанс, что этот символ будет выпадать в будущих Spin.

Toggle Modifier

Нажатие включает или выключает правило. ON действует на все следующие Spin, пока ты его не выключишь или не сбросишь run.

Utility

Force test grid заставляет следующий Spin показать заранее заданные три выигрышные линии.

Technical Event Log

Сырой журнал для отладки. Для понимания очков смотри Score Breakdown под автоматом.
