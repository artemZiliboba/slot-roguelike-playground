# Slot Roguelike Playground

Публичный браузерный playground для раннего тестирования механики `slot-roguelike`.

Здесь намеренно нет production-кода, приватной дизайн-документации, аккаунтов и рейтингов. Репозиторий используется только для быстрого playtest через GitHub Pages.

## Что уже есть

- поле 3x3;
- seeded RNG;
- weighted symbol pool;
- 2-match / 3-match scoring;
- Wild, Bell, Diamond, Bomb;
- тестовые Machine Modifiers;
- Target / Spins / Coins;
- Event Log;
- Developer Controls;
- Force test grid.

## GitHub Pages

В `Settings -> Pages` выбери:

- Source: `Deploy from a branch`
- Branch: `master`
- Folder: `/ (root)`

После публикации playground будет доступен по адресу:

`https://artemziliboba.github.io/slot-roguelike-playground/`

Основной проект и документация находятся в приватном репозитории `artemZiliboba/slot-roguelike`. Этот публичный репозиторий является только playtest surface.
